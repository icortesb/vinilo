# vinilo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una GitHub Action que genera la card de reproducciones recientes de Spotify como SVG estático y la commitea a una rama del propio usuario.

**Architecture:** Módulos ESM puros bajo `src/`, bundleados con `ncc` a `dist/index.js`. El render es una función pura `(tracks, opts) => string`, testeable con snapshots sin red. La red vive aislada en `spotify.mjs` y `art.mjs`; el efecto de git, en `publish.mjs`.

**Tech Stack:** Node 20+, sin dependencias de runtime. Dev: `@actions/core`, `@vercel/ncc`, `node:test`.

**Spec:** `docs/superpowers/specs/2026-09-09-vinilo-design.md`

## Global Constraints

- **Cero dependencias de runtime.** `fetch`, `Intl` y `Buffer` son nativos en Node 20+. `@actions/core` se bundlea; nada más entra.
- **Node 20+**, ESM (`.mjs`), sin TypeScript.
- **Ancho de card: 400px.** Solo el stack de fuentes del sistema.
- **Una falla transitoria nunca reemplaza una card buena por una rota.** Ningún camino de error puede escribir un SVG degradado sobre uno bueno.
- **Todo texto va dentro de un `clipPath`.** El truncado es cosmético; el clip es la garantía.
- Paleta exacta en el spec, sección "Diseño visual". No inventar colores.
- Los mensajes de commit **no llevan trailers de coautoría**.

### Task 4: El render de la card

**Files:**
- Create: `src/render/card.mjs`

- [ ] **Step 1: Test que falla**

test("aparecen los cinco tracks", () => {
  const svg = renderCard(fixture(5), opts());

});

test("un track sin tapa usa placeholder y no rompe", () => {
  const tracks = fixture(5);
  tracks[0].art = null;
  assert.doesNotThrow(() => renderCard(tracks, opts()));

test("un solo track no dibuja filas compactas", () => {
  const svg = renderCard(fixture(1), opts());
  assert.equal(svg.match(/data-row="compact"/g), null);

test("todo texto está dentro de un clipPath", () => {

  const texts = svg.match(/<text[^>]*>/g) ?? [];

  assert.ok(texts.every((t) => /clip-path="url\(#/.test(t)));

test("los caracteres XML del nombre se escapan", () => {

  tracks[0].name = 'A & B <c> "d"';

test("un título de 80 caracteres no desborda", () => {

  tracks[0].name = "x".repeat(80);

test("el alto crece con la cantidad de tracks", () => {

  assert.ok(h(5) > h(2));
